# Politique de sécurité

Les dépôts d'ADOMH Santé hébergent un site public (www.adomhsante.com) et une application de dossier partagé qui traite des **données de santé** (dossier.adomhsante.com).

## Signaler une faille

Écrivez à **manueldelarque@adomhsante.com** et **nicolas@thal.dev**, avec en objet « Sécurité ». Merci de ne pas ouvrir d'issue publique pour une faille.

Indiquez si possible : l'adresse ou la page concernée, les étapes pour reproduire, l'effet constaté. **N'incluez jamais de donnée de santé ni de donnée personnelle réelle** : un exemple fictif suffit.

Vous recevrez un accusé de réception sous 3 jours ouvrés. Une violation de données personnelles est traitée selon la procédure de l'application (notification à la CNIL sous 72 heures si nécessaire).

## Périmètre

- Site : www.adomhsante.com et son administration.
- Application de dossier partagé : dossier.adomhsante.com.
- Les tests automatisés tournent sur des données fictives, jamais sur la production.
